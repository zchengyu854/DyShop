## 8. 规则修订记录（2026-08-06，v1.1 二选一自动取优）

> 背景：原 `allow_stack=0` 对命中会员折扣的订单整券禁用，用户质疑「会员身份为何不能用券」。
> 修订：券永不被会员身份禁用；系统比较「会员价实付」与「原价−券额」，自动采用更省方案。

| 验证场景 | 结果 |
|---|---|
| 金卡(95折) + 保温杯(vip价¥109，会员省¥60) + 满300减30券 | ✅ 自动选会员：applied=false，pay=327（券保持未使用） |
| 金卡 + 耳机(无vip价，会员省¥19.95) + 满300减30券 | ✅ 自动选券：applied=true，pay=369（369<379.05），扣券+快照落库 |
| 下单传券但会员更省 | ✅ 券不扣（仍可用），discount_amount=会员优惠额，pay=会员价 |
| orders 口径 | ✅ total_amount=原价合计，discount_amount=总优惠，pay=total−discount |
| 前端构建 | ✅ 2.87s（摘要区展示 memberBenefit/couponApplied 分支） |
