# 客户端浏览历史模块 — 规格说明（Spec）

> 项目：dyshop 购物程序 · 模块：客户端浏览历史（C 端 `/user/history`，需登录）
> 状态：v1.0 定稿
> 关联：`frontend/src/composables/useRecentViewed.js`（数据层）、`frontend/src/config/userMenu.js`（入口）、`frontend/src/components/user/RecentViewsPanel.vue`（页面）

## 1. 目标

提供完整**浏览历史**闭环：商品详情页自动记录最近浏览（已由 ch04 接入），个人中心新增「浏览历史」页面集中查看、单条移除、一键清空。替代现侧边栏「浏览历史」占位项（当前点击仅 toast「该功能开发中」）。

## 2. 范围

### 2.1 本期（In Scope）

| 编号 | 内容 | 归属 |
|---|---|---|
| S1 | 数据层：`useRecentViewed` 扩充 `remove(id)` / `clear()`，容量 12 → 30 | 前端 |
| S2 | 入口：侧边栏「浏览历史」由 `todo` 占位改为 `link` 路由（`/user/history`） | 前端 |
| S3 | 路由：`/user` 新增子路由 `history`（requiresAuth 由父级继承） | 前端 |
| S4 | 页面：`RecentViewsPanel.vue` — 商品卡片网格（图/名/价）+ 单条移除 + 一键清空 + 空态 + 点击跳详情 | 前端 |
| S5 | 手测用例与记录（docs/ch14/manual-test/history.md） | 文档 |

### 2.2 本期不做（Out of Scope）

- 浏览时间展示与排序：本地记录按浏览先后排序（新在前），不支持改序
- 按登录用户后端同步：浏览历史为设备本地数据，跨设备/跨浏览器不共享
- 去重策略沿用现有：同商品重复浏览仅上移到最新位置（不重复记录）
- 后台管理任何能力：无后端改动，纯前端模块

## 3. 数据模型（前端本地）

- 存储：`localStorage`，key `dyshop:recent-viewed`，值 JSON 数组
- 条目：`{ id, name, mainImage, price }`（price 来自商品接口的元，展示时 `Number(price).toFixed(2)`）
- 上限：30 条，最新在前；超出时丢弃最旧
- 记录时机：商品详情页 `ProductDetail.vue` 加载成功后 `record(product)`（已实现，ch04，本期不回溯）
- 预览复用：个人中心首页「快捷操作与最近动态」卡片展示前 4 条（`RecentActivity.vue` 已实现，本期不变）

```
record(item)  → 去重上移 + 截断 30 + 写 localStorage
remove(id)    → 过滤该 id + 写 localStorage
clear()       → 置空数组 + 写 localStorage
```

## 4. 页面结构（前端）

```
┌──────────────────────────────────────────────────────┐
│ 浏览历史                          共 N 条   [清空]     │  ← 标题行 + 清空操作
├──────────────────────────────────────────────────────┤
│ ┌────────┐ ┌────────┐ ┌────────┐                      │
│ │ 图      │ │ 图  ×  │ │ 图  ×  │  …（网格，最多 30）    │  ← 单条 hover 显移除
│ │ 名称    │ │ 名称    │ │ 名称    │                      │
│ │ ¥价格   │ │ ¥价格   │ │ ¥价格   │                      │
│ └────────┘ └────────┘ └────────┘                      │
├──────────────────────────────────────────────────────┤
│ 空态：暂无浏览记录，去逛逛吧（点击 → 商品列表页）         │
└──────────────────────────────────────────────────────┘
```

- 风格：白色圆角卡片（`--radius-card` / `--shadow-card`），与收藏面板一致
- 交互：
  - 点击卡片主体 → `/products/{id}` 商品详情页
  - 每条右上角移除按钮（hover 显现）→ `remove(id)`，条目即时消失
  - 标题行「清空」按钮 → 二次确认后 `clear()`
  - 空态提示「暂无浏览记录，去逛逛吧」，点击跳 `/products`
- 数据加载：仅组件挂载时读取一次（模块内多实例互不响应式同步，页面级组件每次进入重建，足够）
