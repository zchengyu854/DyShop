# 浏览历史模块 — 手工测试清单（Manual Test）

> 模块：ch14 浏览历史 · 依据 `docs/ch14/spec.md` v1.0
> 环境：前端本地 dev server；需提前在商品详情页产生浏览记录（localStorage `dyshop:recent-viewed`）。

## 1. 记录链路（回归）

- [ ] 浏览商品 A、B、C 详情 → localStorage `dyshop:recent-viewed` 顺序为 C、B、A（新在前）
- [ ] 重复浏览 B → 顺序变为 B、C、A，且无重复条目（去重上移）
- [ ] 浏览第 31 个不同商品 → 最旧条目被挤出（上限 30）
- [ ] 个人中心首页「最近浏览」预览展示前 4 条、点击可跳详情（回归）

## 2. 浏览历史页面

- [ ] 登录后个人中心侧边栏「偏好设置 → 浏览历史」可点击且菜单高亮，进入 `/user/history`
- [ ] 未登录直接访问 `/user/history` → 跳登录页且登录后回跳（父级 requiresAuth 生效）
- [ ] 标题行显示「共 N 条」与记录数一致；网格卡片显示图/名/价
- [ ] 点击卡片主体 → 商品详情页；返回后列表状态保留（keep-alive 回归）

## 3. 移除与清空

- [ ] hover 单条卡片显示移除按钮（触屏点击显现），点击后该条消失且 localStorage 同步
- [ ] 点击「清空」→ 出现二次确认；取消 → 列表不变；确认 → 列表清空 + 空态展示
- [ ] 空态提示「暂无浏览记录，去逛逛吧」，点击跳 `/products`
- [ ] 清空后重新浏览商品 → 记录重新出现（数据层可复用）

## 4. 构建

- [ ] `npm run build` 通过
