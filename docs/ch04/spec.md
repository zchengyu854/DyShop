# 客户端商品详情模块 — 规格说明（Spec）

> 项目：dyshop 购物程序 · 模块：客户端商品详情（C 端 `/products/:id`，公开可访问）
> 状态：v1.0 定稿
> 关联：`backend/dyshop-api`（商品详情接口已有 + 收藏状态接口新增）、`frontend/src/views/shop/ProductDetail.vue`（占位改实现）

## 1. 目标

实现**商品详情页**：相册、价格与购买信息、收藏切换、图文详情、同类推荐；页面风格参考**苹果官网产品页**（白底主区大图左信息右 + 底部灰底推荐区）。

## 2. 范围

### 2.1 本期（In Scope）

| 编号 | 内容 | 归属 |
|---|---|---|
| S1 | 收藏状态接口：`GET /api/user/favorites/status/{productId}`（返回当前用户是否已收藏） | 后端 |
| S2 | 前端 API：`fetchProductDetail`（复用已有 `GET /api/products/{id}`）、`fetchFavoriteStatus` | 前端 |
| S3 | 相册组件 `ProductGallery`：大图 + 缩略图切换（无图兜底 `mainImage`） | 前端 |
| S4 | 信息操作区：名称/副标题/价格（含划线原价）/销量/库存 + 收藏按钮 + 加入购物车/立即购买按钮 | 前端 |
| S5 | 图文详情渲染（`detail` 富文本 v-html）+ 商品不存在（404）处理 | 前端 |
| S6 | 同类推荐区块：复用 `GET /api/products?categoryId=` + 首页 ProductGrid/ProductCard，排除当前商品 | 前端 |
| S7 | 手测用例与记录（docs/ch04/manual-test/product-detail.md） | 文档 |

### 2.2 本期不做（Out of Scope）

- **购物车本体**（后端无购物车接口）：本期「加入购物车 / 立即购买」为**占位按钮**，点击提示"购物车模块开发中"，真实入车/下单由后续模块实现
- 数量选择器（本期购买按钮固定数量 1，购物车模块再做数量交互）
- 商品规格/SKU 选择、评价模块、参数表格
- 详情页收藏**红点动画**等动效（本期仅状态切换）

- 页面打开后：加载 `GET /api/products/{id}`；失败/下架 → 居中"商品不存在"提示（灰底页面）
- 相册：`images[]`（1..n 张）；无 images 时仅显示 `mainImage`；点击缩略图切换大图（当前图高亮）
- 信息操作区：
  - 价格：`price` 大字蓝色/黑色加粗；`originalPrice` 存在时右侧划线灰色
  - 收藏按钮：未收藏=空心爱心 + "收藏"；已收藏=实心 + 高亮色；均显示在价格下方
  - 加入购物车：蓝色胶囊主按钮；立即购买：白色描边按钮；两者点击弹占位提示
- 图文详情：`detail` 为可信后端数据，`v-html` 渲染；限宽 800px 居中，正文排版（标题/段落/图片）
- 同类推荐：`GET /api/products?categoryId={categoryId}&size=8`，前端过滤掉当前商品后渲染网格（≤8 个）；无数据时不显示该区块
- 收藏交互（核心规则）：
  - **未登录**：不调用状态接口（401 会浪费请求），按钮恒为空心"收藏"；点击 → 跳 `GET /login?redirect=/products/{id}`，登录后回跳详情页
  - **已登录**：进入页面调 `fetchFavoriteStatus` 初始化高亮；点击切换 → 调 `POST`/`DELETE /api/user/favorites/{productId}`，**乐观更新**（先改 UI，失败回滚并提示）

## 4. 接口定义

### 4.1 GET `/api/products/{id}` — 商品详情（已有，公开）

响应 `data`（ProductDetailVO）：

```json
{
  "id": 1,
  "categoryId": 1,
  "name": "降噪无线耳机",
  "subtitle": "主动降噪 30 小时续航",
  "mainImage": "https://.../product1/600/600",
  "images": ["https://.../1a/600/600", "https://.../1b/600/600"],
  "detail": "<p>轻量佩戴，ANC 主动降噪…</p>",
  "price": 399.00,
  "originalPrice": 499.00,
  "stock": 200,
  "sales": 156
}
```

- 商品不存在或已下架（status=0）→ `code=404, message="商品不存在"`（本期前端据此渲染"商品不存在"页面）

### 4.2 GET `/api/user/favorites/status/{productId}` — 收藏状态（本期新增，需认证）

- 成功：`data = { "favorited": true }`（true=已收藏）
- 商品不存在 → `code=404, message="商品不存在"`
- 未登录 → `code=401`（前端**仅在已登录时调用**）

### 4.3 复用接口

| 接口 | 用途 |
|---|---|
| `POST /api/user/favorites/{productId}` | 收藏（幂等），ch03 已有 |
| `DELETE /api/user/favorites/{productId}` | 取消收藏（幂等），ch03 已有 |
| `GET /api/products?categoryId={id}&size=8` | 同类推荐（公开），ch01 已有 |

## 5. 数据模型

无新增表。收藏状态由 `favorite` 表（ch03）`user_id + product_id` 唯一键查询得出。

## 6. 非功能要求

- N1：商品详情、推荐接口公开；收藏状态/切换接口需认证（SecurityConfig PUBLIC_PATHS 已覆盖 `/api/products/**`）
- N2：收藏状态接口需校验商品存在（与详情接口一致返回 404）
- N3：收藏切换乐观更新 + 失败回滚，避免竞态误判
- N4：推荐仅取同分类上架商品 ≤8，前端排除当前商品（后端接口无 exclude 参数，前端过滤即可满足本期）
- N5：`detail` 富文本仅渲染后端可信数据（v-html），不允许外部输入注入
- N6：图片 `loading="lazy"`；相册大图切换不重复请求（图片 URL 列表一次加载）
- N7：UI 与全站一致（Apple 风格：白底主区、灰底推荐区、蓝色胶囊按钮 `--blue`、SF 字体栈、18px 圆角卡片）

## 7. 验收标准

1. 打开 `/products/1`：相册、名称、副标题、价格（含划线）、销量、库存、图文详情、同类推荐均正常渲染
2. 相册缩略图点击切换大图，当前缩略图高亮；无 images 商品仅显示主图
3. 收藏：未登录点击跳登录页，登录后回跳；已登录切换状态，刷新后保持（初值正确）
4. 下架商品（如 id=9）与不存在 id → 显示"商品不存在"页面，不报错
5. 加入购物车/立即购买 → 显示"购物车模块开发中"占位提示
6. 同类推荐点击卡片可跳转到对应详情；推荐区不含当前商品
7. 后端新接口 curl 手测通过（见 docs/ch04/manual-test/product-detail.md）
8. 前端 `npm run build` 通过
