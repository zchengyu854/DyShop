## 3. 补充验证（2026-08-06：退款后累计消费扣减）

> 会员等级/消费统计口径修订（ch12）：`annualConsumption`（近 12 月）与 `totalConsumption`（累计）
> 均扣除**已退款售后单**（status=2）的 refund_amount。

| 场景 | 结果 |
|---|---|
| 订单完成（保温杯×5 = ¥545） | ✅ 累计消费 6215.82 → 6760.82 |
| 申请售后 ¥545 → 后台同意退款 | ✅ 累计消费 6760.82 → 6215.82（精确扣减） |
| 近 12 月消费（等级判定口径）同步扣减 | ✅ annualConsumption 同步减少 |
| 退款未完成（待处理/已拒绝/已取消）不影响消费 | ✅ 仅 status=2 计入扣减 |
| 编译 | ✅ EXIT=0 |
