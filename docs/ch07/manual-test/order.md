### 交互失效排查记录（拍平「按钮无法点击」）
根因（已修复）：组件 `PayCountdown.vue` 中 `expiredFired` 误声明为普通布尔量，超时订单（创建超 15 分钟）挂载时执行 `expiredFired.value = true`，对 `false` 写 `.value` 抛出 `Cannot create property 'value' on boolean 'false'`，中断 Vue flush 队列 → 整页响应式冻结，所有按钮/tab 失灵。修复为 `ref(false)`。
同时加固：① 移除整卡 `<router-link>` 内嵌 `<button>` 的非法交互嵌套，改为商品行与操作按钮平级；② router 增加 `scrollBehavior` 每次进入新路由回到顶部，避免半透明 sticky 顶栏遮挡上屏按钮；③ 操作按钮统一 ≥44px 触控目标，`ops` 采用 `flex-wrap: wrap`；④ 修复 flex 容器内 `margin:auto+max-width` 导致页面退化为 fit-content 窄布局（订单页/Cart 页加 `width: 100%`）。
